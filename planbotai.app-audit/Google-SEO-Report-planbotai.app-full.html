2. Audit Categories

2.1 Technical SEO

Score: 96/100

What Works

  • 200 OK responses with clean non-trailing-slash canonical URLs
  • Strict HSTS with preload, DENY framing, nosniff, strict-origin referrer policy
  • Comprehensive robots.txt with query parameter disallow (Disallow: /*?) and sitemap link

Findings

Speculation Rules API Prefetching Low

Modern browsers support Speculation Rules for zero-latency page transitions.
